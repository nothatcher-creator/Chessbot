# ACAS Android M1 notices

This Android detection milestone is inspired by and references A.C.A.S (Advanced Chess Assistance System):
https://github.com/Psyyke/A.C.A.S

A.C.A.S is distributed under GNU GPL version 3. This milestone contains no chess engine and no move-recommendation functionality. It is a detection/diagnostics companion for Lichess on Android.

The chess position reconstruction helper uses bhlangonijr/chesslib (Apache-2.0).
